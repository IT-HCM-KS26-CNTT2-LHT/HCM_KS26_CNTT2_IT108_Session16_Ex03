# Bài 3 : Xử lý Sự cố Giao diện Website Doanh nghiệp

## Phần 1. Phân tích hiện trạng (I/O)

### Quan sát từ ảnh và kiểm tra bằng Inspect Element và tab Computed

Phát hiện phần tử div#lesson-content và div#video-list (2 khum ) đang bị chồng lấn nhau do kích thức khoảng cách không hợp lí  (margin-right âm : -28px kết hợp với width và float : left )

**Box Model gồm 4 thành phần:**
- **Content**: Vùng hiển thị nội dung.
- **Padding**: Khoảng cách bên trong (15px).
- **Border**: Đường viền (2px).
- **Margin**: Khoảng cách bên ngoài (có giá trị âm -28px).

### Sơ đồ Box Model

```
+--------------------------------+
|          Margin (-28px)        |
|   +------------------------+   |
|   |       Border (2px)     |   |
|   |  +------------------+  |   |
|   |  |  Padding (15px)  |  |   |
|   |  |                  |  |   |
|   |  | Content          |  |   |
|   |  | 840 x 600 px     |  |   |
|   |  |                  |  |   |
|   |  +------------------+  |   |
|   +------------------------+   |
+--------------------------------+
```
## Phần 2. Thiết kế giải pháp
**Ta cần loại bỏ margin âm và phân chia lại chiều rộng hai khung:**
- Khung Nội dung bài học:
```
#lesson-content {
    width: 65%;
    float: left;
    margin-right: 2%;
    padding: 15px;
    border: 1px solid #ccc;
    box-sizing: border-box;
}
```
- Khung Danh sách video:

```
#video-list {
    width: 33%;
    float: left;
    margin-right: 0;
    padding: 15px;
    border: 1px solid #ccc;
    box-sizing: border-box;
}
```
